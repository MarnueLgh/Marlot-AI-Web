# Audio Placeholder

This reel is designed to work with text, rhythm and visual motion only.

When a licensed background track is available, place it here as:

```text
assets/audio/musica-fondo.mp3
```

Then add an `<audio>` clip in `index.html` with `data-start="0"`, `data-duration="36"`, `data-track-index="0"` and an appropriate `data-volume`.
